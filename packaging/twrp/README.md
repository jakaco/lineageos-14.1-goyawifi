# LineageOS 14.1 for Galaxy Tab 3 Lite 7.0

For the SM-T110 (goyawifi; some TWRP builds call it goya). The SM-T111 is accepted with a warning: it hasn't been tested and the modem isn't supported. The SM-T210/T211 are refused (wired differently). Install from TWRP 3.x.

The installer checks the device and partition layout, writes SYSTEM and KERNEL, and verifies both. It doesn't touch Recovery or the data partition. Back up System, Data and Boot first.

Source and release notes: https://github.com/jakaco/lineageos-14.1-goyawifi
